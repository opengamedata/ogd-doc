#######################
OpenGameData API Basics
#######################

This unit gives instructions for making use of the OpenGameData APIs.
While these are generally intended for use by data tools rather than by human users, there are some cases where it may be helpful to interact with one of the APIs from your web browser.

In particular, you may find the File API useful for accessing datasets if your game of interest does not yet have a front-end page within the OGD website.
